= Ammitto Switzerland Sanctions Data Repository

== Purpose

This repository stores downloaded and processed sanctions data from the
Swiss State Secretariat for Economic Affairs (SECO) Sanctions Database.

The data is maintained by the Ammitto project and used by the `ammitto` Ruby
gem for querying international sanctions information.

== Legal Basis

Swiss sanctions are implemented through:

* The Federal Act on the Implementation of International Sanctions (Embargo Act, EmbA)
* The Ordinance on Measures against Specific Persons, Undertakings and Objects
* Various country-specific ordinances

Switzerland implements UN Security Council sanctions and also participates
in autonomous sanctions aligned with EU measures where consistent with
Swiss neutrality policy.

== Data Source

* **Authority**: State Secretariat for Economic Affairs (SECO) / Staatssekretariat für Wirtschaft
* **API Endpoint**: https://www.seco.admin.ch/seco/de/home/Aussenwirtschaftspolitik_Wirtschaftliche_Zusammenarbeit/Wirtschaftsbeziehungen/exportkontrollen-und-sanktionen/sanktionsmassnahmen/sanktionsliste.html
* **Format**: XML
* **Update Frequency**: As changes occur in Swiss sanctions regimes
* **Official Source**: https://www.seco.admin.ch/dam/seco/de/dokumente/Aussenwirtschaft/Wirtschaftsbeziehungen/exportkontrollen-sanktionen/Sanktionsliste/Sanktionsliste%20SECO.xml

== Source Data Structure

The `sources/` directory contains source data organized by type:

```
sources/
├── sanction-lists/                    # Sanction list announcements
│   └── consolidated-list/             # SECO Consolidated List
│       ├── entry-001.yml
│       └── ...
├── legal-instruments/                 # Legal instruments
│   ├── embargo-act.yml
│   └── ...
└── supporting/                        # Reference data
    ├── document-types.yml             # Document type definitions
    └── organizations.yml              # Organization definitions
```

=== Schema Types

Each YAML file follows one of the schema types:

. **Announcement Schema** - Standard sanction announcements with `sanction_details`
. **Legal Instrument Schema** - Laws and regulations with structured content

Schema files are located in `schemas/`:

* `schemas/ch-announcement.yml` - For sanction list announcements
* `schemas/ch-legal-instrument.yml` - For legal instruments
* `schemas/document-types.yml` - Supporting schema for document types
* `schemas/organizations.yml` - Supporting schema for organizations

== Source Data Format

=== Sanction Announcement Schema

[source,yaml]
----
# yaml-language-server: $schema=../../schemas/ch-announcement.yml
---
id: ch/lukashenka-dzmitry
announcement:
  title: "Sanktionsliste SECO - Update"
  url: "https://www.seco.admin.ch/..."
  publish_date: "2024-01-15"
  document_type: ch/announcement
  authority: ch/seco
  lang: de

sanction_details:
  - entity:
      type: person
      name:
        full_name: "Lukashenka Dzmitry Aliaksandravich"
        script: Cyrl
        first_name: Dzmitry
        last_name: Lukashenka
      birth_info:
        year: "1980"
      addresses:
        - care_of: "President's Sports Club"
          street: "ул. Старовиленская, 4"
          postal_code: "220029"
      remarks: Travel ban according to article 3 paragraph 1...

    measures:
      - type: asset_freeze
        description:
          en: "All funds and economic resources are frozen"
          de: "Alle Gelder und wirtschaftlichen Ressourcen werden eingefroren"
      - type: travel_ban
        description:
          en: "Travel restrictions apply"
          de: "Reisebeschränkungen gelten"

legal_citations:
  - legal_instrument_id: ch/embargo-act
    citation_type: legal_basis
----

=== CH-Specific Measure Types

[cols="1,3"]
|===
| Measure Type | Description

| `asset_freeze`
| Financial sanctions - freeze of assets

| `travel_ban`
| Travel restrictions - entry ban

| `arms_embargo`
| Restrictions on arms trade

| `trade_restriction`
| General trade restrictions

|===

=== Entity Types

The Swiss sanctions list contains the following entity types:

Person:: Individual persons subject to sanctions
Organization:: Legal entities, companies, and organizations

== Validation and Generation

=== Rake Tasks

The repository provides rake tasks for managing the knowledge graph generation:

[source,shell]
----
# Clean all generated API files
bundle exec rake clean

# Validate source YAML files against schemas
bundle exec rake validate

# Generate API files from source YAML
bundle exec rake generate

# Validate and generate in one step
bundle exec rake build

# Clean and regenerate (recommended for updates)
bundle exec rake regenerate
----

=== Validation

The validation process checks all YAML files against their corresponding schemas:

[source,shell]
----
bundle exec rake validate
----

== Harmonized Data Format

After harmonization, entities are transformed into JSON-LD format using the
Ammitto gem's harmonized models.

=== Entity (JSON-LD)

[source,json]
----
{
  "@context": "https://www.ammitto.org/schema/v1/context.jsonld",
  "@id": "https://www.ammitto.org/entity/ch/lukashenka-dzmitry",
  "@type": "PersonEntity",
  "entityType": "person",
  "names": [
    {
      "@type": "NameVariant",
      "fullName": "Lukashenka Dzmitry Aliaksandravich",
      "script": "Cyrl",
      "isPrimary": true
    }
  ],
  "birthInfo": [
    {
      "@type": "BirthInfo",
      "year": "1980"
    }
  ],
  "addresses": [
    {
      "@type": "Address",
      "street": "ул. Старовиленская, 4",
      "careOf": "President's Sports Club",
      "postalCode": "220029"
    }
  ],
  "sanctionEntryIds": [
    "https://www.ammitto.org/entry/ch/consolidated-list/lukashenka-dzmitry"
  ]
}
----

=== IRI Structure

All resources use normalized IRIs:

```
# Entity (list-agnostic)
https://www.ammitto.org/entity/ch/{local_id}

# Entry (list-specific)
https://www.ammitto.org/entry/ch/{list_type}/{local_id}

# List
https://www.ammitto.org/list/ch/{list_type}

# Legal Instrument
https://www.ammitto.org/legal-instrument/ch/{instrument_id}

# Authority
https://www.ammitto.org/authority/ch
```

=== Available List Types

The Switzerland has one list type: `consolidated-list`

== Knowledge Graph Integration

This repository's source YAML data feeds into the Ammitto knowledge graph
using a normalized structure.

=== Data Flow Architecture

The harmonization process transforms source YAML data into JSON-LD knowledge graph nodes:

....
┌─────────────────────┐     ┌─────────────────────┐     ┌─────────────────────┐
│   Source YAML       │     │   Ammitto Gem       │     │   JSON-LD Output    │
│   (sources/)        │────▶│   Transformer       │────▶│   (api/)            │
│                     │     │                     │     │                     │
│ • Announcement      │     │ • ChAnnouncement    │     │ • Entity nodes      │
│ • Sanction details  │     │ • ChEntity          │     │ • Entry nodes       │
│ • Legal instruments │     │ • ChMeasure         │     │ • Regime nodes      │
└─────────────────────┘     └─────────────────────┘     └─────────────────────┘
....

=== Output Directory Structure

The `api/` directory contains the generated JSON-LD knowledge graph:

....
api/
├── node/
│   ├── entity/
│   │   └── ch/

│   ├── entry/

│   │       └── consolidated-list/

│   ├── regime/
│   │   └── ch_sanctions.jsonld
│   └── authority/
│       └── ch.jsonld
├── search-index.json                      # Search index
└── stats.json                             # Statistics
....

== Updating Data

Data can be updated using the ammitto gem:

[source,shell]
----
# From the ammitto gem directory
bundle exec ruby exe/ammitto fetch ch --format yaml --output-dir ./sources/sanction-lists/consolidated-list
----
